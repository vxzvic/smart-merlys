# SMART — Merly's Scrubsuit

Interactive UX prototype of **SMART: A Web-Based Management Information System for Merly's Scrubsuit** — an e-commerce storefront plus an internal MIS for staff and administrators.

**Live site:** https://vxzvic.github.io/smart-merlys/

Use **Demo controls** (bottom-right) to switch roles or reset the sample data.

## Notes
- Static site (HTML/CSS/JS). Sample data is stored in each visitor's browser; there is no backend.
- No payment gateway: payments are submitted by customers and verified manually by staff.
